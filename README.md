all scripts are in package.json - scripts

to run a script, use `npm run <script name>`

## project setup 

create the database file `users.csv` in `src/` 

create a `.env` file in the project root with the line `SESSION_SECRET=<your session secret>`

## to start the development server

in project root:

install all dependencies `npm install`

to start the server `npm run dev`

## extras

to format all files `npm run format`
